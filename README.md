# Mob Health v2

[Download the PLugin](https://modrinth.com/plugin/mob-health)

Changes the mobs name to display it's health amount. Supports custom mob names after you renamed a mob.

![Loading server chart...](https://faststats.dev/embed/default:edb0ef29-841d-4551-8a62-f042632f7132:servers-and-players?theme=light)
 
 ## ⚙️ Settings

- Skyblock Level Prefix (enabled/disabled)
- Show names through blocks (enabled/disabled)
- Disable mob name (enabled/disabled)
- Name color ("&c")
- Edit prefix and suffix for both profiles
- Change colors of the health displayed (high / mid / low HP colors)
